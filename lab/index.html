Tus apuntes, en todos tus dispositivos.

Ensayo aislado con datos ficticios. La nube y las cuentas se simulan en esta página. No conecta con Supabase ni lee los apuntes de tu app.

Primero: descargar cada copia → comprobar archivos y contenido → revisar importación → confirmar. Crear una cuenta nunca sustituirá el archivo local.

1. Revisión antes de importar

Ordenador: copia pendienteMóvil: copia pendienteTablet: copia pendienteNube real: acceso pendiente

Ejemplo: 1 apunte ficticio, 0 adjuntos. Destino: cuenta de prueba Ana. Acción: añadir una copia; conservar el original.

La migración de datos reales permanece bloqueada.

2. Prueba la sincronización

Escribe y espera 600 ms. Desconecta dos dispositivos, escribe versiones diferentes y reconéctalos. Ambas versiones quedarán disponibles para revisar. La cuenta Bea debe permanecer vacía.

3. Recuperar versiones

Un conflicto no elimina ninguna versión. Elegir una versión crea una nueva revisión recuperable.
